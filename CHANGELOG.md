# Изменения AG Design Community

## 0.47.6

- После ручной проверки в Help приложение снова проверяет GitHub в срок. Если GitHub недоступен, приложение повторяет попытку через час.

## 0.47.5

- Нативное приложение проверяет наличие новой версии на GitHub. Проверку можно запустить вручную из меню Help.
- В Help видно, доступна ли новая версия. Оттуда можно прочитать изменения и открыть страницу с установщиками.
- Агент сообщает об обновлении после завершения задачи. Напоминание об одной версии появляется не чаще раза в три дня.
