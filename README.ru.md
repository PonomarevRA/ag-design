# AG Design

**Знания о дизайне, переиспользуемые компоненты и проверяемые композиции интерфейсов — локально.**

[English](README.md) · [Установка](INSTALL.ru.md) · [Документация](docs/wiki/Home-ru.md)

Система помогает людям и агентам выбирать готовые компоненты, собирать экраны и проверять результат. В проект входят живой каталог, справочник с первоисточниками, песочница композиций, примеры приложений и MCP-сервер.

[Скачайте установщик](https://github.com/PonomarevRA/ag-design/releases/latest) для macOS, Windows или Linux.

## Быстрый запуск

Нужны **Python 3.11+**, **Node 22+** и npm.

```sh
git clone https://github.com/PonomarevRA/ag-design.git
cd ag-design
python3 tools/install.py
.venv/bin/python -m ag_design
```

Откройте loopback-адрес из вывода приложения. Предпочтительный порт — 8897; если он занят, выбирается собственный свободный. Windows: `py -3 tools/install.py`, затем `.\.venv\Scripts\python.exe -m ag_design`. [Ручная установка и desktop](INSTALL.ru.md).

Основной каталог работает локально, ключ облачного API ему не нужен. Точный поиск и SQLite FTS5 доступны без модели; смысловой поиск использует отдельно устанавливаемую локальную модель.

## Установка агентом

> Прочитай AGENTS.md и INSTALL.ru.md. Установи этот checkout и комплектный навык ag-design для своего клиента. Сохрани существующие навыки и MCP-серверы. Проверь фактические адрес, версию и доступность инструментов.

```sh
python3 tools/install.py --agent codex
```

Поддержаны также `cursor` и `claude`. `--scope project` устанавливает навык в проект. Отличающийся существующий навык сохраняется. Фрагмент MCP создаётся в `.ag-design/mcp.json` для явного подключения; настройки клиента не перезаписываются.

## Устройство проекта

| Каталог | Назначение |
| --- | --- |
| `ag_design/` | Локальный HTTP/MCP, каталог, поиск и проверки |
| `web/` | Каталог, песочница, справочник и примеры приложений |
| `packages/components/` | Контролы, компоновки, чаты, графики и lifecycle |
| `packages/rules/` | Офлайн-рекомендации, сетки и контракты проверок |
| `packages/visual-tools/` | Самостоятельная библиотека визуальных элементов |
| `packages/interaction-tools/` | Самостоятельная библиотека взаимодействий |
| `catalog/` | Описания и чистые стартовые данные библиотеки |
| `skills/ag-design/` | Переносимые инструкции агентам |
| `docs/wiki/` | Версионируемая документация для GitHub Wiki |

Поставляются четыре независимых пакета. Компоненты потребителя работают без запущенного каталога и соседнего checkout. Палитра, данные, маршруты и полномочия остаются у приложения.

Читайте: [архитектура](docs/wiki/Architecture-ru.md), [работа через MCP](docs/wiki/Using-MCP-ru.md), [компоненты и проверки](docs/wiki/Components-and-review-ru.md), [данные и публикация](docs/wiki/Publishing-ru.md).

## Разработка

```sh
npm ci --ignore-scripts
npm run build
npm test
python3 -m pip install -e '.[test]'
python3 -m pytest -q
python3 tools/verify_repository.py --git
```

Сборки в `dist/` не входят в Git. Данные и редактируемая библиотека находятся вне checkout в системных каталогах **AGDesignCommunity** и **AGDesignCommunityLibrary**; доступны явные переопределения.

Числа геометрии, клавиатура, доступность, контент и проверка реального потребителя оцениваются отдельно. Переданный через API отчёт не является независимой сертификацией. Собственный публичный код — [MIT](LICENSE); сторонние библиотеки, шрифты и ресурсы сохраняют свои лицензии и уведомления. Для изменений используйте pull request с результатами проверок; предполагаемые секреты не публикуйте в issue.
