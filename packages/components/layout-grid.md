# Layout grid inspection

Read `layout-grid-selection`, `nested-layout-grids` and `layout-grid-inspection` before choosing profiles. `design_layout_grids` discovers authored use/avoid guidance. Golden Canon remains the preferred creative starting point; operational forms, reading and controls have their own reasons for other grids. Bento is a modular composition, not a separate mathematical grid.

`layoutGridGeometry`, `checkLayoutGrid` and `checkLayoutGridTree` are pure offline functions. A scope has a stable ID, parent ID, border-box rectangle, grid and explicit anchors. Scope rectangles are parent-local; anchor coordinates are scope-local. Units `css-px`, `pt`, `emu` never mix. Defaults use a 96-CSS-px reference inch; declare your host-specific dimensions, leading, margins and gaps. This does not qualify a particular typography or native renderer.

Fourteen types: `golden-canon`, `columns`, `modular`, `baseline`, `spacing`, `thirds`, `manuscript`, `edge-balance`, `lead-room`, `center-perspective`, `phi-grid`, `golden-triangle`, `diagonal-flow`, `icon-keylines`. Columns measure x lines; baseline needs an actual y and `baselineSource`; other profiles default to 2D points. Frame edges are not baselines or optical image foci. Missing measurements return unknown. Golden uses the compatible reduced `ag-diagonal-core-v1`, not a copied BONT asset or phi grid. Regular lattices expose axis coordinates; their Cartesian product is not allocated.

`inheritAxes` projects parent guides into the child, reports each axis source and marks composite targets `ag-inherited-guides-v1`. It does not implement CSS subgrid sizing. Independent local profiles may differ across levels. Choose anchors/tolerance before inspection; default tolerance is0.008 of the carrier's shorter side. A hit is geometric evidence only.

Bounds:32 scopes,256 anchors total,257 lines/axis,512 lines/scope,2048 lines/tree. Invalid inputs throw before a report/overlay replacement. `createLayoutGridOverlay({report})` consumes the same numeric report, returns a pointer-transparent aria-hidden SVG, stable `update`, defensive-copy `report`, idempotent `dispose`. Include the stylesheet and provide a visible text equivalent. It installs no observer, timer or network access and never changes host layout. Draft is not consumer qualification.


Every profile has a current bilingual `grid-<type>` wiki chapter and interactive schematic. See `@ag-design/rules/composition-grids.md` for purpose selection. Cinema/photo defaults are authored AG templates, not externally prescribed ratios. `edge-balance` takes `edge` (four sides), `insetRatio` (.05–.4), `focusRatio` (.1–.9). `lead-room` takes left/right `edge`, `eyeLevel` (.1–.6); declared looking direction is not image recognition. `center-perspective` takes `vanishX/Y` (.1–.9). `golden-triangle` and `diagonal-flow` take boolean `flipX/Y`. Other types reject these options. Perpendiculars use actual width/height, not stretched square geometry.

`kind: "guide"` measures the nearest **finite** diagonal segment or circle, with explicit x/y. It does not substitute arbitrary axis intersections. `icon-keylines` centers an unstretched square in a rectangular carrier; optional `geometry.circles` and `regions` are guide data. Inherited axes intentionally clear local point/segment/circle/region targets and retain per-axis provenance. Existing seven local profile semantics are preserved.

Overlay `markerScale` (.001–4, default1) changes diagnostic marker sizes only, not numeric distances, coordinates, tolerance or host layout. PPTX diagnostic copies include editable line, circle and region outlines; native PowerPoint rendering remains unknown until qualified.

`createGridIconDraft({symbol,purpose,grid,label,strokeWidth})` returns original bounded starter SVG, primitive data, visible stroke bounds and the same numeric report. Symbols: `play`, `focus`, `image`, `compass`. UI purpose uses24 units with `icon-keylines` or `spacing` (default step2); illustrative purpose uses64 units and may use framing grids. Surrounding column/reading grids are not single-glyph construction grids. Stroke1–3, literal nonblank label at most80 UTF-16 units. No supplied paths, scripts, external SVG resources or network access. `currentColor` inherits host color policy; no palette override. The constructor requires host-owned accessible names/decorative semantics, real-size legibility and optical review. Geometric hits never prove recognition or professional quality.
