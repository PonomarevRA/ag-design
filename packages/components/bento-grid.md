# Бенто-сетка

`createBentoGrid({label, items, columns, minColumnWidth, gap, rowMinHeight, alignItems})` компонует готовые HTML-блоки по общим колонкам и строкам. Элемент `{id, content, colSpan, rowSpan}` задаёт устойчивый идентификатор, HTMLElement и размеры. Подключайте общий `styles.css`; оформление карточек и их содержание задаёт приложение.

Бенто подходит для обзора продукта, возможностей и dashboard с разной значимостью модулей. Размер подчёркивает иерархию. Для равнозначных карточек обычно проще равные ячейки, для независимой естественной высоты — `masonry-layout`. Существующую Pinterest-ленту каталога эта фабрика не меняет. Таблицы и последовательные формы сохраняют свою семантику.

Число колонок определяется шириной контейнера. В одну колонку rowSpan становится 1, высота — естественной. Плотное заполнение и CSS-перестановка не используются: задавайте осмысленный исходный порядок и проверяйте его с Tab. Вложенная сетка — отдельная фабрика со своим временем жизни.

`update()` сначала проверяет параметры, затем сохраняет прежние узлы по ID, состояние полей и фокус у оставшегося элемента. `refresh()` обновляет размеры вручную, если ResizeObserver недоступен. `getLayout()` возвращает локальные координаты в CSS px, колонки, spans и stale без текста и значений полей; устаревший замер надо обновить. `dispose()` отключает собственное наблюдение и удаляет корень; вложенные компоненты освобождает хозяин.

Пределы: 64 блока, 1–12 колонок, colSpan 1–12, rowSpan 1–6. Значения по умолчанию: 4 колонки, минимальная ширина 200px, gutter 16px, минимальная строка 140px. Это настройки AG, не требования WCAG.

Проверяйте 320px, увеличенный текст, длинное содержимое, RTL, изменение ширины контейнера, отсутствие наложений и горизонтальной прокрутки, сохранение фокуса и освобождение ресурсов. Числовая сетка не заменяет визуальную и AT-проверку.

`alignItems: "start"` сохраняет естественную высоту карточек и выравнивает их верхние края: короткая активность не растягивается за длинной таблицей. Пустое место под коротким блоком остаётся фоном сетки. `"stretch"` (по умолчанию, для совместимости) заполняет выделенные строки/span и подходит для выраженных крупных модулей. DOM-порядок и общий gutter сохраняются; это не masonry-упаковка. `getLayout().alignItems` сообщает выбранный режим; bounds отражают реальные размеры wrappers.
