# Чипсы выбора

`createChoiceChips({label,options,value,onChange,disabled})` использует нативную radio-группу из `createSegmentedChoice`. Подходит для 2–6 коротких взаимоисключающих режимов или фильтров. Названия и переводы задаёт приложение.

Чипсы располагаются в одной строке. При нехватке места используется горизонтальное пролистывание касанием, трекпадом и клавиатурой. Полоса прокрутки скрыта. Стрелки выбирают доступные варианты, Tab переводит фокус в группу и из неё. Выбранный с клавиатуры вариант становится видимым. `setValue(value)` меняет значение без вызова пользовательского callback. `dispose()` снимает обработчики.

Подключайте общий `styles.css`. Сохраняйте достаточно места для полного текста каждого чипса. При длинных формулировках используйте select или список radio с переносом. Для фильтров со счётчиками есть `createFilterChips` в дополнительной библиотеке interaction-tools. Для настоящих панелей вкладок используйте tabs.

Проверяйте LTR/RTL, узкую ширину, увеличенный текст, видимый focus, disabled, последнюю скрытую опцию и отсутствие горизонтальной прокрутки страницы. Реальная touch-проверка остаётся отдельной от браузерной проверки размеров и keyboard.
