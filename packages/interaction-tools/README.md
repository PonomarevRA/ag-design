# AG interaction tools 1.0.0

Original framework-independent AG factories with no runtime dependencies or network requests. Import `@ag-design/interaction-tools` and its `styles.css`; semantic `--ag-*` tokens come from the host profile. Light/dark profiles, reduced motion and literal text are supported. Public examples contain only synthetic data.

- `createToastStack({document,label,onDismiss})`: append `element`, then `push({message,id?,duration?,actionLabel?,onAction?})`. At most five records; a full queue returns `null` without changing existing notifications. Duration is0(persistent) or2000–30000ms; default5000. Hover, focus and hidden document pause remaining monotonic time. Action removes the toast before calling host business logic, once; close/Escape restores its origin focus when possible. `dismiss(id)`, `clear()` and `dispose()` release timers/listeners. Dispose calls no host effects. Host owns placement, event transport and business undo; this surface is not a modal or transaction rollback engine.
- `createFilterChips({items,selectedId?,label?,onChange?})`: at most50unique local IDs, literal labels, optional count0–1e9and boolean disabled. Native pressed buttons in a group request host filtering; no panels are created. Arrow/Home/End select enabled choices; RTL reverses horizontal arrows. Enter/Space use native button activation. `update({items?,selectedId?})` validates before replacing DOM, remains silent and preserves stable focus. If a selected choice disappears, first enabled choice becomes current. An empty/all-disabled set has no selection. Host provides counts and data; this component computes neither.
- `createAnimatedNumber({value,decimals,locale,label,animated})`: finite numeric data ±1e12,0–4decimals, Intl locale. `update(number)` publishes the exact formatted accessible value immediately and rolls changed characters for240ms. It does not animate intermediate business values. Motion is skipped/cancelled for hidden/offscreen/reduced-motion content; no idle RAF/timer. Missing Web Animations support falls back to a static result. `dispose()` cancels effects and releases observer/media/document subscriptions. No automatic ticking, remote quotes or live-region announcements are imposed on frequently changing metrics.

Append components before interacting; dispose before removing or replacing owned content. These short examples do not need an extra render-window; catalogue cards already own lazy lifecycle. A host may use existing render-window for larger compositions while pinning active user input. Browser/GPU/native memory must be measured separately from jsdom load counters.

Public API is intentionally host-owned. Host callbacks can throw; a toast is already removed before its action callback runs. Manual screen-reader and physical-touch certification have not been performed. Code and assets from tweb are not imported/copied. Source-pattern research and provenance are in the repository engineering report; public catalogue references standards.
