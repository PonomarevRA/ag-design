# Установка

[English](Installation.md) · [Главная](Home-ru.md)

Нужны Python3.11+, Node22+ и npm. В корне clone/ZIP выполните:

```sh
python3 tools/install.py
.venv/bin/python -m ag_design
```

В Windows используйте `py -3` и `.venv\Scripts\python.exe`. Открывайте адрес из вывода, а не заранее выбранный порт. Ручные команды, Linux desktop и устранение проблем описаны в `INSTALL.ru.md` / `INSTALL.md` репозитория.

Добавьте `--agent codex`, `cursor` или `claude` для установки навыка. `--scope project` выбирает проектную область. Отличающийся навык не перезаписывается. Есть режимы `--skill-only` и `--dry-run`. Явно добавьте подготовленный `.ag-design/mcp.json` к конфигурации клиента, сохранив другие серверы, затем переподключитесь.

Это исходная поставка, а не готовый нативный установщик. `--desktop` ставит дополнительные desktop-зависимости; особенности ОС проверяются отдельно. Основному приложению облачные ключи не нужны. Локальная модель смыслового поиска устанавливается отдельно.
