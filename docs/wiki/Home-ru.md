# Документация AG Design

[English](Home.md)

Начните с [установки](Installation-ru.md), затем прочитайте [архитектуру](Architecture-ru.md) и [работу агентов](Using-MCP-ru.md). [Проверки компонентов](Components-and-review-ru.md) связывают отдельные элементы с реальным экраном. [Публикация](Publishing-ru.md) описывает границу исходников и локальных данных.

В проекте есть локальный каталог, справочник с источниками, песочница композиций и примеры приложений на заглушках. Компоненты работают в приложении-потребителе; каталог помогает их выбирать, разрабатывать и проверять.

Исходники этих страниц находятся в `docs/wiki/`: документация доступна из clone/ZIP и проходит ревью вместе с кодом. Эти страницы доступны прямо в GitHub и clone/ZIP; отдельное зеркало GitHub Wiki можно включить позже.
