# AG Design documentation

[Русский](Home-ru.md)

Start with [installation](Installation.md), then read [architecture](Architecture.md) and [the agent workflow](Using-MCP.md). [Component review](Components-and-review.md) explains how reusable parts and real screens are checked. [Publishing](Publishing.md) describes the source/data boundary and contribution checks.

AG Design contains a local catalogue, a source-backed Design Book, a composition sandbox and stub-backed application examples. The project includes portable components/rules and independent visual/interaction libraries. Components run in the consumer; the catalogue is a development tool.

These pages are maintained under `docs/wiki/` in the repository, so documentation changes receive the same review as code. The versioned Markdown is available directly in GitHub, a clone or ZIP; a separate GitHub Wiki mirror is optional.
