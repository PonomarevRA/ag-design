# Агенты и MCP

[English](Using-MCP.md) · [Главная](Home-ru.md)

1. Узнайте реальные инструменты и прочитайте `design_status`.
2. Перед компонентом вызовите `design_brief`, сохраните текущие версию и hash политики.
3. Ищите по назначению через `design_search`, затем читайте `design_component`. Пустое точное совпадение не доказывает отсутствие основы.
4. Найдите главу через `design_rule_sections`, прочитайте её через `design_rule_section`; для задачи/этапа/платформы используйте `design_recommendations`. Пример: `Atomic Design` и глава `atomic-design-composition`.
5. Переиспользуйте реальные фабрики и варианты, сохраняя семантику и палитру хоста.
6. Проверьте реальные состояния и контексты; передайте актуальные наблюдения и разберите unknown/unchecked. Числа геометрии не исполняют клавиатурный сценарий или AT.

В песочнице используйте объявленные операции композиции, document/revision/pins и idempotency keys. Описательный JSON-рецепт не является аргументами API. Подробности загружаются по запросу при стабильных схемах MCP.

Установщик добавляет навык по явному выбору. Фрагмент MCP подключается с сохранением существующих серверов/настроек; после установки нужен reconnect.
